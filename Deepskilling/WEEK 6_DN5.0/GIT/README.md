# Git Hands-On Lab Submission

This workspace contains five completed, self-contained Git hands-on exercises.

| Folder | Exercise | Final result |
|---|---|---|
| `01-git-setup-and-first-commit` | Configuration and first commit | `welcome.txt` committed on `master` |
| `02-gitignore` | Ignore rules | Log files and `logs/` excluded from tracking |
| `03-branching-and-merging` | Branch and merge | Feature branch merged and deleted |
| `04-merge-conflict-resolution` | Conflict resolution | Conflict resolved, backup files ignored |
| `05-cleanup-and-push` | Cleanup and push | Clean `master` pushed to its local bare remote |

## Notes

- Every exercise folder is an independent Git repository with its own commit history.
- The documents in each folder explain the commands performed and the verification result.
- The fifth exercise keeps its local bare remote inside its own folder to demonstrate `pull` and `push` without requiring private GitLab credentials. Its remote can be replaced with the GitLab project URL before submission if required.
